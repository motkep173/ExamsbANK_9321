# מאגר הבחינות באלגברה לינארית להנדסה (214.1.9321)

מאגר שאלות ממבחני ובחני עבר בקורס, מסודרות לפי נושאים, עם פתרונות מלאים וחוברת PDF של כל המבחנים והפתרונות.
אוניברסיטת בן־גוריון בנגב · היחידה להוראת קורסי יסוד.

הפרויקט נבנה עם הסקיל `exam-question-bank` (בתיקייה `.claude/skills/`). כדי להתחיל, פתחו session של Claude Code
על המאגר הזה, צרפו את קובצי ה־PDF של המבחנים ובקשו: „בנה מאגר שאלות ממבחני העבר בקורס”.

## מבנה

- `data/course.json`: פרטי הקורס (שם, מספר, מוסד, יחידה, לוגו)
- `data/exams.json`: רשימת המבחנים והבחנים
- `data/taxonomy.json`: נושאים ותתי־נושאים לפי סדר הסילבוס
- `data/questions/<examId>.json`: השאלות והפתרונות של כל בחינה
- `app/template.html`: תבנית האתר; `index.html` נבנה ממנה
- `tools/`: בנייה, בדיקה וחוברת

## פקודות

```bash
cd tools && npm install && cd ..   # פעם אחת: MathJax לבדיקה ולחוברת
python3 tools/validate.py          # בדיקת הנתונים
python3 tools/build.py             # בניית index.html
python3 tools/booklet.py           # בניית booklet.pdf
```

קובצי ה־PDF המקוריים של המבחנים נשמרים בתיקייה `exams/` ואינם נכנסים ל־git.
